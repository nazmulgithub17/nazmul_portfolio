# 🌐 Nazmul Hassan – Personal Portfolio Website

A modern, animated, and fully responsive personal portfolio website built using **HTML, CSS, and Vanilla JavaScript**.  
This portfolio showcases my **education, skills, and contact information** with a visually rich UI and smooth animations.

- 📱 Fully responsive (Mobile, Tablet, Desktop)
